# Andrew's coding agent plugins

[Andrew Stack](andrew-stack/) configures Andrew’s engineering policy across coding projects. It includes shared workflow instructions, verification and release rules, and agent-specific setup. See the [installation guide](andrew-stack/README.md) for supported agents, prerequisites, and updates.

```bash
git clone https://github.com/andrew-clk/plugins
cd plugins
bash andrew-stack/scripts/install.sh
```

[pstack](pstack/) supplies the engineering playbooks used by Andrew Stack. Its [Claude Code package](harness/pstack/) is generated from that source. The marketplace also retains [Origin Apps](origin-apps/) for existing users. The complete upstream collection of Cursor plugins and integrations is available in [cursor/plugins](https://github.com/cursor/plugins).
